# Inventário de equipamento

Ferramenta do gabinete digital para confirmar que os PC e os hotspots estão na escola, lendo o código de barras das etiquetas.

Funciona toda no aparelho. Não envia dados para nenhum servidor. O registo fica guardado só no telemóvel de quem a usa.

Abrir: https://danielacaetano121186-pixel.github.io/inventario-equipamento/

No iPhone, instale no ecrã principal (Partilhar > Adicionar ao ecrã principal). Assim funciona sem rede e o iPhone não apaga o registo.
O sw.js guarda uma cópia da página no aparelho. Só trata a página do inventário; as outras pastas do site não são afetadas.
